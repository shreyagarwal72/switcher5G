5G NSA (non-standalone) uses 5G radio with an LTE network helping in the background. Most carriers started here. 5G SA (standalone) uses a full 5G core network on its own. It can give lower latency, but only works if your carrier has turned it on. 4G LTE keeps the phone off 5G completely.

In the app these map to NR_ONLY (SA), NR_LTE (NSA) and LTE_ONLY.

  1. Install the Shizuku app and open it.
  2. On Android 11 or newer, turn on Developer options, then Wireless debugging, pair, and tap Start in Shizuku. On older versions, or without Wi-Fi, start it from a computer with the ADB command Shizuku shows.
  3. Open Switcher 5G and tap Request Shizuku Permission. Allow it.
  4. Pick a mode and tap Apply.

The setup dialog inside Switcher 5G can copy the ADB command for you, including a version for when you are already inside adb shell.

Shizuku started through Wireless debugging or ADB stops when the phone reboots. Start it again from the Shizuku app. If you have root, Shizuku can start itself on boot, which avoids this.

If your phone is rooted with Magisk, KernelSU or APatch, set the engine to Root (or leave it on Auto) and tap Grant Root (su) Access. Approve the superuser prompt. Then choose your SIM slot and mode.

  • Engine not ready. Shizuku is not running, permission was not granted, or root was denied.
  • Carrier does not support it. Many networks do not offer 5G SA. The phone accepts the setting but stays on NSA or LTE.
  • Wrong SIM. On dual-SIM phones, check that the right slot is selected.
  • Phone firmware blocks it. Some phones ignore the request. Try the RadioInfo engine and set the type there.

If it still fails, send us a bug report. See the support page.

Switcher 5G asks Android to change the preferred network type, so any phone that allows that can work. Whether you actually get 5G SA depends on your carrier, your plan and your phone’s modem. Release 1.0.5 added fixes for Airtel and Vodafone Idea in India, and for Samsung Galaxy phones running One UI 8.5. If your device or carrier misbehaves, tell us on Telegram so it can be fixed.

The app only changes the preferred network type, the same setting that the hidden RadioInfo menu changes. It does not flash modem files or touch system partitions. It is reversible. If you lose signal after switching to 5G SA, switch to 5G NSA or 4G LTE.

You can also dial *#*#4636#*#*. If none open, your phone maker removed it. Use Shizuku or root instead.
