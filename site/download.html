All official releases are signed with the same key, so updates install over older versions without errors.

To check on your phone, open Termux and run:

sha256sum ~/storage/downloads/switcher5g-release.apk

Install steps

  1. Tap Download APK above and wait for the file to finish.
  2. Open the file from your notifications or your Downloads folder.
  3. If Android asks, allow installs from this source (your browser or file manager).
  4. Tap Install, then Open.
  5. Follow the three setup steps to authorize Shizuku or root.

Switcher 5G can also check for new versions itself and install them in one tap. You can turn this off in Settings.

Automatic updates

Pick one way to stay current.

Obtainium (recommended)

  1. Install Obtainium.
  2. Tap Add app and paste https://github.com/shreyagarwal72/switcher5G.
  3. Tap Add. Obtainium reads each GitHub release and offers the new APK.

In-app updater

Switcher 5G checks GitHub Releases when you open it, shows what changed, and installs the new APK after you confirm.

F-Droid and other stores

Switcher 5G is not in the main F-Droid repository yet. The project includes a metadata file so it can be added. Until then, use Obtainium or this page.
